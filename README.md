# Risk-Aware Commissioning of EEG Motor Imagery Brain-Computer Interfaces Under Channel and Calibration Constraints

Motor imagery brain-computer interfaces translate imagined movements into device commands. Safe deployment requires low false-command rates during rest and a practical system setup. This study framed EEG BCI deployment as a staged commissioning problem rather than a universal deploy- ment decision. EEG motor imagery data from 105 subjects drawn from the PhysioNet EEG Motor Movement/Imagery Dataset were analyzed using cue-paced rest-versus-intent command gating. Signals were processed in the 8–30 Hz band. Log-variance channel features were extracted, and logistic regression models were evaluated on held-out runs. The primary policy used 21 subject-personalized channels, 60 calibration trials, and a target accepted-command coverage of 0.30. A readiness gate was applied using four calibration criteria: balanced accuracy, false-command rate, coverage, and minimum accepted trials. The readiness- gated policy deployed 57.1% of held-out folds, achieving an accepted balanced accuracy of 0.858 and an unconditional false- command rate of 0.016 versus 0.046 for an all-channel always- deploy comparator, a 65.2% reduction. This gain is not free: unconditional coverage also fell, from 0.326 to 0.146, so false- command rate normalized per unit of accepted coverage fell by a more modest 22.0% (0.141 versus 0.110). Subject-level decoding performance was also highly heterogeneous, ranging from chance to near-ceiling balanced accuracy. These findings show that risk- aware commissioning improves deployment safety while making the safety-access trade-off, and its true magnitude, explicit.
